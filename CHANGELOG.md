# Changelog

## 0.1.0 — 2026-10-09

- CSV, JSONL, JSON and optional read-only XLSX inputs.
- Schema validation, filters, SQLite grouping and atomic exports.
- Decimal arithmetic without binary floating point conversion.
- Error statistics, structured logs and CSV formula neutralization.

- Lossless JSON/JSONL fractional-number decoding and type-aware Decimal group keys.
- Invalid configuration types, numeric filters and contradictory bounds fail before IO.
